# Programming Fundamentals and Unit Testing - September 2023

## About the Course
The "Programming Fundamentals and Unit Testing" course explores fundamental programming concepts essential for effective and high-quality learning in professional modules on automated testing. Participants build upon the knowledge acquired in the QA Fundamentals (Manual) module and begin to study basic programming techniques, including writing introductory-level code, working with an Integrated Development Environment (IDE), and using variables and data. The course covers operators, expressions, console operations (input and output), conditional constructs (if, if-else), loops (for, while, do-while), and component testing. It also includes basic programming structures such as arrays and lists, providing a foundation for advanced automated testing modules.

### Skills You Will Acquire:
- Component Testing (Unit Testing)
- Handling standard programming language functionality
- Working with linear data structures
- Declaring and invoking methods
- Understanding fundamental concepts of automated testing

### Who Is This Course For?
This course is suitable for anyone with a foundational knowledge of software testing processes, fundamental concepts of software technologies, an understanding of the software development lifecycle, and CI/CD concepts.
